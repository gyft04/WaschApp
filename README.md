# WaschApp

A web-based prototype for reserving washing machines in student residences.

The application was developed as a university project in Human-Computer Interaction and focuses on simple booking flows, usability and user-centered design.

This repository is a portfolio version of a collaborative university project. My individual contributions are documented below.

## Main Features

- Washing machine overview
- Weekly slot selection
- Booking confirmation
- Reservation management
- Cancellation logic
- Different slot states: available, occupied and blocked

## My Contribution

My main responsibility was the development of the testable prototype.

I worked on:

- Page implementation and navigation
- Booking and cancellation logic
- Slot state handling
- UI integration and technical corrections
- Preparation of usability tests
- Improvements based on user feedback

## UX & Testing

The project included:
